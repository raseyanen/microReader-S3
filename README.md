# microReader-S3 — электронная шпаргалка на e-paper (ESP32-S3)

Порт microReader на **ESP32-S3 Super Mini** с e-paper **WeAct 1.54" (200×200, SSD1681)**, джойстиком на 5 положений и двумя кнопками. Файлы загружаются по USB: устройство открывается на компьютере как **USB-накопитель**.

## Что есть и чего больше нет

- Есть: чтение `.txt` (перенос по словам, кириллица), `.md` (текст, формулы TeX, таблицы Markdown, графики по формуле и по таблице), `.tex`; глубокий сон с продолжением чтения с того же места; USB-накопитель.
- Нет (по сравнению с версией для ESP32-C3): игры (e-paper обновляется 0,3–2 с — динамические игры невозможны), Wi-Fi/веб-интерфейс/OTA (заменены USB-накопителем), PIN-код, картинки `.itxt`.

## Подключение (config.h — поправьте под свою плату)

| Назначение | GPIO |
|---|---|
| e-paper: SCK / MOSI / CS / DC / RST / BUSY | 12 / 11 / 10 / 9 / 8 / 7 |
| Джойстик: вверх / вниз / влево / вправо / центр | 1 / 2 / 4 / 5 / 6 |
| Кнопки A (назад) / B (вперёд) | 13 / 14 |

Все кнопки между пином и GND. Нельзя использовать GPIO19/20 (USB), 26–32 (флеш/PSRAM); GPIO0/3/45/46 — strapping. Центр джойстика должен быть на GPIO0–21: он будит из глубокого сна.

## Настройки Arduino IDE

| Параметр | Значение |
|---|---|
| Board | ESP32S3 Dev Module (ядро esp32 2.0.14+ или 3.x) |
| **USB Mode** | **USB-OTG (TinyUSB)** — иначе не соберётся (`#error`) |
| USB CDC On Boot | Disabled |
| USB Firmware MSC On Boot | Disabled |
| Flash Size | 4MB |
| PSRAM | Disabled (если на плате нет PSRAM) |
| Partition Scheme | любая: используется `partitions.csv` из папки скетча (раздел `ffat` ≈ 2,4 МБ) |

Библиотеки: **GxEPD2** (с Adafruit GFX), **EncButton**.

Прошивка: зажать BOOT, нажать и отпустить RESET, отпустить BOOT, затем Upload (в режиме USB-OTG автосброса нет). Если при выборе размера экрана или другой модели панели нужно, замените класс `GxEPD2_154_D67` в `microReader-S3.ino` и `EPD_NATIVE` в `config.h`.

## Управление

| Где | Вверх / влево / A | Вниз / вправо / B | Центр |
|---|---|---|---|
| Меню | выше | ниже | клик — открыть, **удержание — режим USB** |
| `.txt` | страница назад | страница вперёд | **удержание — выход** |
| `.md`, `.tex` | назад / прокрутка | вперёд / прокрутка | клик — режим «страницы → верт. → гор. прокрутка»; **удержание — выход** |

Джойстик и кнопки A/B дублируют друг друга. Центр, зажатый при включении, сразу открывает режим USB. Через 2 минуты без нажатий устройство засыпает (страница остаётся на экране), центр будит и открывает файл на том же месте.

## USB-накопитель

1. Удерживайте центр в меню (или при включении), подключите кабель к компьютеру.
2. Появится диск «MicroRdr Reader» (FAT). Копируйте файлы `.md`, `.txt`, `.tex` в корень, папки не поддерживаются.
3. Безопасно извлеките диск (или удержите центр) — устройство перезагрузится и обновит список.

На время режима файловая система в прошивке размонтирована. Раздел использует сектор 4096 байт (как у FFat в ядре) — современные Windows/macOS/Linux его поддерживают; если диск не определяется, смотрите «Проблемы».

## Формат `.md`

Секции `## Название`. Страницы секции: текст, формулы (`tex: ...`), таблица (`| a | b |`), графики (`plot: ...`). Примеры — в папке `examples`. Логический экран 100×100 (каждая точка удваивается, `EPD_SCALE = 2` в `config.h`; значение 1 даёт 200×200, но мелкий текст).

```
## Дискриминант
Квадратное уравнение имеет корни, если D >= 0.
tex: D = b^2 - 4ac
tex: x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}

## Графики
plot: y = sin(x); y = cos(x); x = -2*pi..2*pi; y = -1.5..1.5
plot: table x=1 y=2,3
```

## Проблемы

- **Накопитель не появляется:** проверьте `USB Mode: USB-OTG (TinyUSB)`, используйте кабель с данными, подключайте к порту USB, а не к хабу без питания. Для отладки откройте UART0 (GPIO43/44): при `USB CDC On Boot: Disabled` `Serial` выводит туда.
- **«ОШИБКА ФС»:** не применился `partitions.csv` (в логе строка `ffat ОШИБКА`) — прошивайте с Erase All Flash.
- **Перезагрузка при старте:** включён PSRAM на плате без него.
- **Остаточное изображение:** раз в 8 обновлений делается полное обновление; уменьшить число — `EPD_FULL_EVERY`.
